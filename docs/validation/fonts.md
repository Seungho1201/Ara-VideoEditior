# 제목 글꼴과 폰트 추가

2026-09-28, Apple Silicon / macOS 27, 시스템 언어 한국어.

## 동작

- 텍스트 클립의 인스펙터 **TEXT**에서 **Font**(패밀리)와 **Style**(굵기·기울기)을 고른다.
  - 패밀리를 바꾸면 지금 글꼴과 굵기가 가장 가까운 스타일이 선택된다. 이탤릭 여부도 유지된다.
  - 같은 굵기에 여러 폭이 있으면 보통 폭이 선택된다.
  - 판단은 글꼴의 속성 값(trait)으로 한다. 스타일 이름은 사용자 언어로 오기 때문에("볼드 이탤릭체") 판단에 쓰지 않는다.
- **Add Font…**(제목 인스펙터), **File → Add Fonts…**, 창이나 시작 화면에 끌어놓기로 TTF·OTF·TTC·OTC 파일이나 폰트가 든 **ZIP**을 추가한다.
  - 제목 인스펙터의 버튼으로 추가하면 새 글꼴이 그 제목에 바로 적용된다.
  - 다른 경로로 추가하면 폰트만 추가하고, 무엇이 추가됐는지 알림으로 알려준다.
- 추가한 폰트는 `~/Library/Application Support/com.framestudio.editor/Fonts`에 복사해 Ara 프로세스에만 등록한다.
  - 받은 원본을 옮기거나 지워도 계속 쓴다. 심볼릭 링크는 가리키는 실제 파일을 복사한다.
  - 시스템 폰트 목록(Font Book)은 바뀌지 않는다.
- 다음 파일은 추가하지 않고 이유를 알려준다.
  - 이미 추가한 같은 파일(SHA-256 비교)
  - 이 Mac에 이미 있는 글꼴
  - 설치된 글꼴과 같은 이름이 섞인 컬렉션. 등록하면 앱을 끌 때까지 그 설치 글꼴을 가리기 때문이다.
  - 지원하지 않는 형식과 읽을 수 없는 파일
  - ZIP 안의 `__MACOSX`, 숨김 파일, 링크
- 제목은 글꼴을 PostScript 이름(예: `GmarketSansBold`)으로 저장한다.
  - 이름은 정확히 일치하는 글꼴로만 찾는다. 일반 폰트와 가변 폰트가 함께 설치된 패밀리도 고른 그대로 쓴다.
  - 글꼴 정보가 없는 이전 문서는 원래 글꼴인 Helvetica Neue Bold로 연다. 이전 Ara는 새 문서의 글꼴 이름을 무시하고 연다.
- 문서의 글꼴이 이 Mac에 없을 때:
  - 이름은 그대로 두고 Helvetica Neue Bold로 그린다.
  - 인스펙터에 주황색으로 표시하고, 프로젝트를 열 때 알림으로 알려준다.
  - 폰트를 추가하거나 Font Book에 설치하면 그 제목을 다시 그린다.
- 글꼴 변경은 한 번의 Undo다. 제목은 미리보기에서 바로 다시 그리고 전체 재빌드는 하지 않는다. 미리보기·스냅샷·출력은 같은 글꼴로 그린다.
- 줄 높이 밖으로 그려지는 글자(G마켓 산스의 g·j·p·q·y, Zapfino의 장식획)도 잘리지 않는다.
  - 제목 이미지의 여백을 실제 잉크 범위에 맞춰 사방으로 늘린다.
  - 글자가 여백 안에 들어가는 제목(기본 글꼴 포함)은 이전과 픽셀 단위로 같은 이미지를 쓴다.

## 실제 검증

- `~/Downloads/GmarketSansOTF.zip`·`GmarketSansTTF.zip`으로 확인했다.
  - "G마켓 산스"(`GmarketSansLight/Medium/Bold`)와 "G마켓 산스 TTF" 두 패밀리, 6개 스타일이 추가됐다.
  - 같은 ZIP을 다시 넣으면 "already added"로 건너뛴다.
  - 기본 굵기의 제목에 추가하면 `GmarketSansBold`가 적용되고, Style에서 Light로 바꾼 뒤 Undo로 되돌아간다.
- `FrameProbe fonts TestArtifacts/fixtures <출력> ~/Downloads/GmarketSans*.zip` 결과:
  - 두 줄 제목(`G마켓 산스 Ara 2026 / gjpqy 한글`, 120pt)이 기본 글꼴과 다르게 그려진다(평균 차이 0.027).
  - 제목 이미지 가장자리에 잉크가 없어서 잘림이 없다.
  - 없는 글꼴은 기본 글꼴과 똑같이 그려진다(차이 0.0).
  - MP4 출력과 스냅샷이 일치한다(차이 0.0016).
  - 저장·다시 열기 후에도 글꼴이 유지된다.
- `FrameProbe smoke`에 같은 검사가 들어 있다. 여기서는 시스템 폰트(Georgia Bold)의 이름만 바꿔 어떤 Mac에도 없는 폰트를 만들어 쓴다. 폰트 파일은 저장소에 넣지 않는다.
- 단위 테스트:
  - FrameCore `TitleFontTests` 3개: 저장·이전 문서·검증·초기화
  - FrameStudio `FontLibraryTests` 9개
    - 추가·복사·등록·목록·렌더
    - ZIP 정리, 중복·설치된 폰트·가짜 파일·빈 ZIP 거부, 링크는 실제 파일로 복사
    - 한국어 환경의 이탤릭 선택
    - 기본 글꼴 이미지가 이전과 같은지, Zapfino 잘림 없음
    - 없는 글꼴 대체와 추가 후 미리보기 다시 그리기
    - 한 번의 Undo, 끌어놓은 폰트가 미디어가 아닌 폰트로 들어가는지
  - 전체 121개 통과.
- 적대적 검토(에이전트 14개)에서 확인된 문제를 모두 고쳤다.
  - 한국어 macOS에서 패밀리를 바꾸면 Bold Italic이 선택됨
  - 일반 폰트와 가변 폰트가 함께 있으면 "없는 폰트"로 판정됨
  - 없는 폰트를 추가해도 미리보기가 기본 글꼴로 남음
  - 줄 높이 밖의 글자가 잘림
  - 제목을 선택하지 않고 폰트를 추가하면 아무 표시가 없음
- 기존 smoke·snapshot·스냅샷 색 왕복·출력 독립 검사가 모두 통과했다.
