# 실제 검증 결과

검증일: 2026-09-21. Apple Silicon Mac, macOS 27.0, Xcode 27.0 / Swift 6.4. 외부 의존성 없는 Swift 6 모드로 빌드했다. macOS 15는 최소 빌드 대상이며 실제 실행 검증 OS와 구분한다.

## 빌드 및 단위 테스트

- Debug와 Release ARM64 빌드 성공. `file` 결과 `Mach-O 64-bit executable arm64`.
- `vtool -show-build`: `platform MACOS`, `minos 15.0`.
- 개발용 ad-hoc 서명 후 `codesign --verify --deep --strict` 성공.
- XCTest **8개 통과, 실패 0개**. [원본 로그](core-tests.log), [Release 빌드 로그](release-build.log).
- 시간: 지원 프레임률 모두 1,000,000프레임 누적 드리프트 검사.
- 편집: 연결 영상/오디오 분할·앞뒤 트림·다른 트랙 이동, sourceStart/타임라인 위치 분리, 잘못된 편집의 원자성, 연결 삭제, 스냅.
- 저장: fractional fps·북마크·클립 속성을 포함한 JSON encode/decode 동일성, Undo/Redo 왕복.
- 잘못된 문서: 버전·트랙 겹침·극단적 정수 시간·잘못된 속성을 오류로 거부. 정수 overflow가 발생하기 전에 범위를 검사한다.

## 실제 미디어 통합 테스트

`FrameProbe`가 생성 픽스처를 AVFoundation으로 읽고 앱과 동일한 구성/합성/출력 코드를 호출했다. [로그](media-smoke.log).

- MP4 2종·PNG·WAV 가져오기, 메타데이터·대표 썸네일·오디오 파형·북마크 생성/해석.
- 분할·소스 트림·타임라인 이동 뒤 저장/재열기 모델 동일성.
- V1/V2 겹침, 회전·축소·위치·불투명도·밝기·대비·채도, 컬러 텍스트, 클립 볼륨·음소거.
- 영상이 없는 구간 위 텍스트, 이미지 전용 4K, 오디오 전용 타임라인.
- 미리보기 구성과 인코딩 결과의 5개 시점 프레임 비교: 정규화 RGB 평균 차이 최대 **0.00262**, 허용 기준 0.035.
- 실제 실행 중인 60초 출력의 취소: 취소 예외, 최종 파일 없음, `.work` 및 partial 파일 없음 확인.
- 목적지가 디렉터리인 출력 실패: 기존 내용 보존 및 임시 폴더 정리.
- 누락 미디어·손상 파일·PQ HDR 입력의 명시적 실패.

## 독립 출력 분석

FFprobe/FFmpeg는 테스트 도구로만 사용한다. 앱이 이들을 실행하지 않는다. [분석 JSON](independent-validation.json), 재현 스크립트 `scripts/verify-outputs.py`.

| 출력 | 해상도 | 프레임률 | 프레임 수 | 영상 길이 | 오디오 길이 |
|---|---:|---:|---:|---:|---:|
| 편집 합성 | 1920×1080 | 30 | 195 | 6.500000s | 6.500000s |
| 이미지+텍스트 | 3840×2160 | 30 | 30 | 1.000000s | 1.000000s |
| 오디오 전용 | 1920×1080 | 30 | 30 | 1.000000s | 1.000000s |
| 유리수 프레임률 | 1920×1080 | 30000/1001 | 31 | 1.034367s | 1.034375s |

모두 H.264 / AAC 스테레오 48kHz, 시작 시간 0, BT.709 primaries/transfer/matrix 확인. fractional fps는 nominal뿐 아니라 average fps도 30000/1001로 일치한다. 오디오 길이는 48kHz 샘플 정밀도에서 검사했다.

출력 PCM의 왼쪽 채널을 원본과 비교했다. 볼륨 0.25에 대해 RMS 비율 **0.2438**(AAC 손실 허용 범위 이내), 빈 구간 RMS **0**, 음소거한 880Hz 오버레이의 유입 없음. 원본 구간을 옮긴 뒤 예상 비프 위치 0/1/2/4.5/5.5초와 검출 위치 차이는 모두 **0.36ms 미만**이었다. 독립 픽셀 검사로 붉은 바닥, 이동·회전·축소한 V2 영상, 빈 구간의 민트 텍스트, 최상위 정지 이미지를 확인했다.

## 실제 GUI 검사

앱을 실행하고 컴퓨터 사용 도구로 수행했다. 검증 중 사용자 입력과 겹친 구간은 자동 검증 결과로 계산하지 않고 입력을 분리한 뒤 다시 검사했다.

- 파일 선택 창에서 영상 가져오기 → 이름/길이/해상도/fps/썸네일 표시.
- 라이브러리 썸네일을 V2에 드롭 → V2/A2 연결 쌍 생성.
- 시작 8초 6프레임에서 9초 6프레임으로 연결 이동.
- 끝 손잡이 트림: 6초에서 5초로 연결 쌍 단축.
- 재생 헤드 11초 1프레임에서 분할 → Undo → Redo → 오른쪽 키로 11초 2프레임.
- 텍스트를 `Frame Studio — 편집 테스트`로 수정, 미리보기 표시 확인.
- 다른 이름으로 저장 후 JSON에서 모든 연결 쌍의 start/sourceStart/duration/mediaID 동일성 확인.
- 저장된 문서를 앱 재실행 후 재열기, 기존 원본 접근·썸네일·파형·타임라인 복원.
- 최종 Release에서 앱이 저장한 문서를 다시 열고 재생·일시정지 및 한글 텍스트 렌더링 확인. 다른 실행 파일에서 만든 북마크는 앱의 접근 권한으로 취급하지 않고 Relink를 요구하도록 수정했다. 유효하지만 오래된 북마크 갱신은 UI 스레드 밖에서 수행한다.
- 실제 내보내기 설정/파일 선택/진행률 15% 표시/완료 UI 확인. 결과 `GUI-Automation.mp4`: **1080p, 30fps, 426프레임, 14.2초, H.264/AAC**.
- 일부러 없는 원본 경로를 가진 별도 문서를 열어 Missing/Relink/재연결 안내 표시 확인. 정상 원본으로 Relink 후 썸네일·미리보기 복구 및 새 북마크 저장.

사용자가 편집한 검증 상태는 `TestArtifacts/fixtures/GUI-Session.framestudio`에, 이후 자동 조작은 `GUI-Automation.framestudio`에 별도로 보존했다.

## 검증하지 않은 항목

- macOS 15 실기기, 다양한 Apple Silicon 세대의 성능, Intel/Rosetta, 서명·공증·샌드박스 배포.
- 수 시간 원본·수천 클립·장시간 스크러빙 스트레스, 모든 카메라 코덱·손상 유형·가변 프레임률 소스 조합.
- Finder에서 여러 외부 파일을 동시에 드롭하는 GUI 시나리오와 HDR 게인맵/HLG/Apple Log 각각의 실제 픽스처. 해당 코드 경로는 구현했지만 테스트한 PQ HDR 거부와 혼동하지 않는다.
- GUI 취소 버튼 클릭의 종단 검증. 출력 엔진의 실행 중 취소·정리는 자동 통합 테스트로 검증했다.
- 색상계측 장비를 사용하는 방송용 색 정확도 검증, 시스템 충돌·전원 차단 중 출력 복구.
