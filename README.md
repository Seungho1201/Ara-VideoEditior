# Ara

macOS 15 이상 / Apple Silicon ARM64용 로컬 영상 편집 MVP. Swift 6, SwiftUI·AppKit, AVFoundation, Core Image와 Metal 장치를 사용하는 CIContext로 구현했다. 외부 Swift 패키지, 웹뷰, 서버 처리 없이 가져오기 → 타임라인 편집 → 미리보기 → 프로젝트 저장 → MP4 출력이 연결된다.

## 빌드·실행

Xcode 16 이상과 Swift 6 툴체인이 필요하다. 검증 환경은 Xcode 27 / Swift 6.4 / macOS 27 / ARM64다.

```sh
./scripts/build-app.sh
open "build/Ara.app"
```

기본 빌드는 ARM64 Release다. Debug는 `./scripts/build-app.sh debug`. Xcode에서 `Package.swift`를 열어 `Ara` executable을 실행해도 된다. Xcode 설치 경로가 다르면 `DEVELOPER_DIR`를 지정한다. 전역 `xcode-select` 설정은 변경하지 않는다.

앱 이름은 Ara, 고정 강조색은 연푸른색 `#9ACBFF`다. SwiftUI 컨트롤과 AppKit 타임라인의 선택·재생 헤드·드롭 표시·오디오 파형에 같은 색상을 사용한다. 기존 문서와 미디어 북마크 호환성을 위해 내부 앱 식별자와 `.framestudio` 확장자는 유지한다.

앱은 개발용 ad-hoc 서명이다. 배포용 Developer ID 서명·공증·App Store 샌드박스 패키징은 포함하지 않는다. 앱을 종료한 뒤 같은 경로에 다시 빌드한다.

## 사용 순서

1. 앱을 파일 없이 실행하면 **시작 화면**이 뜬다. 열었거나 저장한 프로젝트가 최근 순으로 포스터·프레임률·길이·클립 수와 함께 모인다. **Add Project… / New Project / ⌘N**을 누르면 이름·화질(Full HD/4K)·화면비·프레임률 설정 창이 열린다. **Create Project**로 빈 타임라인을 만들고, **Cancel**은 기존 작업을 그대로 유지한다. 설정은 프로젝트 파일에 저장되고 화질은 Export의 기본 해상도로도 사용된다. 기존 프로젝트는 카드를 더블클릭하거나 Return으로 열고, 폴더·파일을 목록에 드롭해 한 번에 모을 수 있다. 편집 중 **⇧⌘1**로 돌아오며, Esc로 편집을 이어간다. Finder에서 프로젝트를 열거나 `--project`/`--import`로 실행하면 곧바로 편집기로 간다.
2. **Export / ⌘E**에서 영상 비율(16:9·9:16·1:1·4:3·4:5)과 프레임률과 출력 해상도를 선택한다. **Apply**는 설정만 적용하고, **Choose destination…**은 저장 위치를 골라 설정을 적용한 뒤 MP4를 출력한다. **Cancel**이나 저장 위치 선택 취소는 설정을 바꾸지 않는다. 편집 중에도 바꿀 수 있으며 한 번의 Undo로 복원한다. 재생 속도·원본 시작점·연결 A/V를 유지하며 컷 경계를 새 프레임 격자에 맞춘다. 한 프레임보다 짧아져 사라질 클립이나 원본 범위 때문에 변환할 수 없는 컷은 변경 없이 안내한다.
3. **Import / ⌘I**로 영상·오디오·PNG/JPEG/8-bit TIFF를 가져온다. Finder 파일을 라이브러리 또는 타임라인에 드롭해 가져올 수도 있다.
4. 라이브러리 **썸네일을 원하는 트랙·시간에 드래그**한다. 더블클릭 또는 `+`는 V1/A1 끝에 추가하며 우클릭 메뉴로 대상 트랙을 고를 수 있다. 영상의 원본 오디오는 같은 번호의 오디오 트랙(V3 → A3)에 연결 클립으로 들어간다. 트랙 이름 열 맨 위의 **＋ Video**는 가장 위 영상 트랙 위에, 맨 아래의 **＋ Audio**는 가장 아래 오디오 트랙 아래에 새 트랙을 추가한다(각 최대 8개, ⌘Z로 취소). 연결 오디오가 들어갈 트랙이 없으면 자동으로 만든다. 추가한 트랙(V3·A3 이상)이 비어 있으면 이름 옆 **✕**로 지울 수 있고, 그 위 트랙들이 한 칸씩 내려온다(연결 클립은 짝을 유지한 채 함께 내려오며, 내려갈 자리가 차 있으면 지우지 않는다). 트랙이 타임라인 높이를 넘으면 세로로 스크롤되며 눈금자는 위에 고정된다.
5. 클립 중앙을 드래그해 이동하고 양끝 손잡이로 트림한다. **타임라인 눈금자나 빈 트랙 공간을 누르고 드래그**하면 스키밍 바가 따라온다. 버튼을 놓으면 멈추며, 클릭 없이 포인터만 움직여서는 위치가 바뀌지 않는다. 클립 끝의 양쪽 **5프레임 이내**에서는 정확한 끝 경계로 이동하고 `CLIP END` 표시가 나타난다. 확대 배율과 관계없이 프로젝트 프레임률을 기준으로 하며, **Shift**를 누르거나 **N**으로 스냅을 끄면 주변 프레임을 자유롭게 탐색한다. 선택 클립은 **⌘B**로 재생 헤드에서 분할한다.
6. 인스펙터에서 변형·색상·볼륨을 조절한다. **Text / ⇧⌘T**는 재생 헤드 위치에 3초 텍스트를 추가한다. 그 구간의 모든 영상 클립보다 위 트랙(최소 V2)에 놓이며, 그 트랙이 없으면 새로 만든다. 텍스트 클립의 인스펙터 **TEXT**에서 **Font**(글꼴)와 **Style**(굵기)을 고른다. **Add Font…** 또는 **File → Add Fonts…**로 TTF·OTF·TTC 파일이나 폰트가 들어 있는 **ZIP**을 그대로 추가할 수 있고, 텍스트 클립을 선택한 채 추가하면 새 글꼴(지금 굵기에 가장 가까운 것)이 바로 적용된다. 폰트 파일이나 ZIP을 창에 끌어다 놓아도 추가된다. 추가한 폰트는 Ara 전용 폴더(`~/Library/Application Support/com.framestudio.editor/Fonts`)에 복사해 Ara 안에서만 등록하므로, 받은 원본 파일을 지워도 계속 쓰고 시스템 폰트 목록은 바뀌지 않는다. 글꼴 변경은 한 번의 Undo로 되돌린다.
7. 인스펙터 옆 **TRANSITIONS** 탭에서 화면 전환 효과를 고른다. 타일에 마우스를 올리면 미리보기가 재생된다. 타일을 타임라인의 **두 클립이 맞닿은 컷**에 드래그하면 컷 중심에 전환이, **클립의 시작·끝**에 드래그하면 페이드 인·아웃이 들어간다. 클립을 선택한 뒤 Start/End를 고르고 타일을 클릭해도 된다. 타임라인의 전환을 클릭하면 인스펙터에서 종류·방향(←→↑↓)·길이를 바꾸고, **Delete**로 지운다. 이미 전환이 있는 자리에 다른 종류를 놓으면 길이·방향을 유지한 채 종류만 바뀐다.
8. **⌘S**로 `.framestudio` 프로젝트를 저장한다. 원본 파일은 프로젝트에 복사되지 않는다. 원본이 없으면 라이브러리의 **Relink**로 연결한다.
9. **Export / ⌘E**에서 HD 또는 4K를 선택하고 MP4를 저장한다. 선택한 비율에 맞는 픽셀 크기가 표시되며, 세로 9:16은 1080×1920 또는 2160×3840이다. 출력은 H.264 + AAC 스테레오, SDR Rec.709, 현재 프로젝트 프레임률이다.
10. 타임라인 툴바의 **카메라 / ⇧⌘E**는 현재 프레임을 **프로젝트 비율의 sRGB PNG**로 저장한다(짧은 변 1080px). 미리보기와 같은 컷·합성·텍스트·효과를 반영하며, 앱 창의 크기와 관계없이 캔버스 전체를 캡처한다. 재생 중에는 일시정지하고 저장 위치를 선택한다. 프로젝트 끝에서는 마지막 유효 프레임을 사용한다. 이전 색공간 수정 전 버전의 PNG는 원본 영상에서 다시 캡처해야 한다.
11. 미리보기 재생 컨트롤의 양끝 버튼 또는 **⌥← / ⌥→**로 선택 클립의 처음·마지막 프레임으로 이동한다. 끝 시간은 다음 클립의 첫 프레임이 아니라 선택 클립 안의 마지막 프레임이다. 화면 밖으로 이동하면 타임라인도 따라 스크롤한다.
12. 미리보기의 영상·이미지·텍스트를 **더블클릭**하면 파란 테두리와 네 모서리 조절점이 나타난다. 안쪽을 드래그하면 이동하고 모서리를 드래그하면 반대 모서리를 기준으로 비율을 유지하며 크기가 바뀐다. 핀치 또는 **⌥+스크롤**은 중심을 기준으로 확대·축소한다. 변경은 인스펙터와 저장·출력에 반영되며 한 번의 드래그는 한 번의 Undo로 복원된다. **Esc**는 변형 모드를 닫고, 드래그 중 누르면 해당 드래그를 취소한다. 외곽선과 조절점은 창의 **최상위 레이어**에 그려져 타임라인·패널 위로 넘어가도 잘리지 않고, 캔버스 밖으로 나간 부분은 **불투명도 30%**로 보인다. 조절점과 외곽선 테두리는 어디서든 잡을 수 있어 캔버스 밖으로 완전히 나간 클립도 되돌릴 수 있으며, 클립 몸체는 프리뷰 안에서만 잡혀 그 아래의 재생 버튼·인스펙터·타임라인은 그대로 동작한다. 타임라인에 포커스가 있을 때의 Esc도 변형 모드를 닫는다.

| 조작 | 동작 |
|---|---|
| Space | 재생 / 일시정지 |
| ← / → | 이전 / 다음 프레임 |
| ⌥← / ⌥→ | 선택 클립의 처음 / 마지막 프레임 |
| ⇧⌘E | 현재 합성 프레임을 PNG 스냅샷으로 저장 |
| Shift + ← / → | 타임라인에 포커스가 있을 때 10프레임 이동 |
| ⌘B | 선택 클립 및 연결 오디오 분할 |
| ⌘C / ⌘V | 타임라인 선택 클립 복사 / 재생 헤드 위치에 붙여넣기 |
| Delete | 선택 클립 및 연결 오디오 삭제 |
| ⌘Z / ⇧⌘Z | Undo / Redo |
| N | 경계·재생 헤드 스냅 켜기/끄기 |
| 눈금자 / 빈 트랙 클릭·드래그 | 재생 헤드 이동 / 누르는 동안 스키밍 |
| Shift + 드래그 | 해당 드래그의 스냅 해제 |
| 핀치 / Zoom 슬라이더 | 타임라인 확대·축소 |
| 가로 스크롤바 / 트랙패드 | 타임라인 수평 이동 |
| ⇧⌘S | 다른 이름으로 저장 |
| ⇧⌘1 | 시작 화면(프로젝트 목록) |

타임라인을 클릭한 뒤 **⌘C**로 선택 클립과 연결 오디오를 복사한다. **⌘V**는 복사한 트랙의 재생 헤드 위치에 트림·효과·볼륨을 유지한 새 클립을 만든다. 같은 트랙의 기존 클립과 겹치면 붙여넣기를 취소하고 안내한다. 프로젝트 간 복사는 프레임률이 같아야 하며, 인스펙터의 텍스트 입력칸에서는 일반 텍스트 복사·붙여넣기가 작동한다.

**Timeline → Trackpad Haptics**로 스키밍·스크럽과 미디어 드래그의 햅틱을 끌 수 있다. macOS **시스템 설정 → 트랙패드 → 포인트 및 클릭 → 세게 클릭 및 햅틱 피드백**도 켜져 있어야 한다. Force Touch 트랙패드에 손가락이 닿아 있을 때 일반 이동은 간격을 제한한 `generic`, 클립 끝 스냅은 `alignment` 시스템 피드백을 요청한다. 같은 끝에서 반복 울리지 않으며, 끝 경계 피드백이 일반 이동보다 우선한다. macOS 공개 API에는 강도 조절이 없고 실제 피드백은 장치·시스템 설정에 따른다. 햅틱 설정은 앱을 다시 열어도 유지된다. 끝 스냅은 **끝 경계(다음 클립의 시작 또는 빈 구간)**이며, 선택 클립 안의 마지막 프레임으로 가는 **⌥→**와 구분된다.

미디어 라이브러리에서 타임라인으로 드래그하면 배치 가능한 트랙에 진입할 때 `generic`, 클립 경계·재생 헤드·타임라인 시작에 스냅될 때 `alignment`, 배치 완료 시 `generic` 피드백을 요청한다. 같은 트랙에서 자유롭게 이동하거나 같은 경계에 머무를 때는 반복 울리지 않는다. 잘못된 트랙, 클립 겹침, 누락 미디어, 취소된 드래그에는 완료 피드백이 없으며 **Shift** 또는 스냅 끄기로 드래그 정렬도 해제할 수 있다.

## 구현 범위

- 리사이즈 가능한 라이브러리·프로그램 모니터·인스펙터·타임라인, 어두운 네이티브 UI. 기본 가로 비율은 **미디어 34.5% / PROGRAM 42.7% / 인스펙터 22.8%**, 위아래는 1:1이며 조절한 비율은 재실행 후 복원한다. 작은 창에서는 각 패널의 최소 폭·높이를 우선한다. PROGRAM 양옆 분할선을 움직이면 영상 좌우 여백을 각각 50pt까지 줄일 수 있다. 라이브러리·인스펙터는 최대 폭 제한 없이 늘어나며, 미리보기는 프로젝트에서 선택한 영상 비율을 유지한다.
- 미디어 라이브러리는 **한 줄에 두 개씩** 배치하는 그리드다. 16:9 썸네일 안에 원본 비율을 유지해 표시하고, 파일명·길이·해상도·프레임률과 선택 테두리를 제공한다. 더블클릭·추가 버튼·타임라인 드래그 동작을 유지한다.
- 기본 영상 2개·오디오 2개 트랙, 각각 최대 8개까지 추가. **번호가 높은 영상 트랙이 위**에 합성된다(V3 > V2 > V1). 같은 트랙 내 겹침은 거부한다. 트랙 수는 프로젝트에 저장되며, 트랙 수 정보가 없는 이전 문서는 2+2로 열린다.
- 선택, 연결 이동·시작/끝 트림·분할·삭제, 스냅, 프레임 이동, NDF 타임코드, Undo/Redo 100단계.
- 위치, 크기, 회전, 불투명도, 밝기·대비·채도, 볼륨·음소거, 한글 포함 텍스트·글꼴·굵기·폰트 크기·색상.
- **폰트 추가**: TTF·OTF·TTC와 그 ZIP을 받아 Ara 폴더에 복사하고 이 앱 프로세스에만 등록한다(설치된 폰트와 같은 이름, 이미 추가한 같은 파일은 건너뛴다). 텍스트는 글꼴의 PostScript 이름으로 저장되며, 그 폰트가 없는 Mac에서 열면 이름은 유지한 채 Helvetica Neue Bold로 그리고 인스펙터에 주황색으로 알린다. 폰트를 다시 추가하면 원래 글꼴로 돌아온다. 미리보기·스냅샷·출력이 같은 글꼴로 그린다. 글꼴 정보가 없는 이전 문서는 기존 글꼴(Helvetica Neue Bold)로 연다.
- 비동기 메타데이터·썸네일·파형 분석, 디스크 캐시, 구간 중심 타임라인 그리기, 오래된 재생 구성·seek 취소/무시.
- 버전 1 JSON 편집 문서, 원본 구간/배치 구간 분리, 원자적 저장, 보안 범위 북마크, 누락 미디어 재연결.
- 미리보기·출력이 같은 합성기/효과/오디오 믹스를 사용한다. 빈 구간, 정지 이미지·텍스트만 있는 프로젝트, 오디오 전용 프로젝트도 출력한다.
- **미리보기는 프로젝트 비율에 맞춘 HD 크기(짧은 변 1080px)**로 합성한다. 16:9는 1920×1080, 9:16은 1080×1920이며, 1920×1080(세로 1080×1920)을 넘는 영상은 가져오는 즉시 백그라운드에서 **1080p 프리뷰 프록시**를 만든다. 프록시는 HEVC(원본이 10-bit면 Main10), 0.2초 간격 키프레임, 프레임 재정렬 없음이며, 원본과 같은 타임스탬프(원본 타임스케일 그대로)·색 태그(HLG/PQ/709)·HDR 메타데이터 유무·회전 정보를 유지한다. 알파 채널이 있거나, 픽셀이 정사각형이 아니거나, 인코더가 받지 않는 색 태그(예: BT.470BG)가 붙은 영상은 프록시를 만들지 않고 원본으로 미리보기한다. 미리보기 영상만 프록시를 읽고 **소리·출력·스냅샷은 항상 원본**을 읽는다. 프록시가 준비되기 전에는 원본으로 미리보기하며, 진행률은 하단 상태 표시줄에 보인다. 재생 중이거나 드래그 중에 프록시가 완성되면 끊김 없이 다음 일시정지(끝까지 재생되어 멈춘 경우 포함) 때 전환한다. 가져오기를 Undo하면 진행 중인 프록시 생성도 멈추고, 실패한 프록시는 Relink하거나 프로젝트를 다시 열면 다시 시도한다. 프록시는 `~/Library/Caches/com.framestudio.editor/proxies`에 저장되고, 원본 파일이 바뀌면 새로 만들며, 30일 동안 쓰지 않으면 지운다. 시스템이 캐시를 비우면 원본으로 미리보기하고 다시 만든다.
- 스크럽·프레임 이동은 seek를 쌓거나 취소하지 않고 **하나씩 쫓아간다**(Apple QA1820). 진행 중인 seek는 합성 프레임이 화면에 그려질 때 끝나고, 그 사이 재생 헤드가 움직였으면 곧바로 최신 위치로 다시 seek한다. 모든 seek는 프레임 정확이며, 스크럽 직후 재생은 재생 헤드 위치에서 시작한다. 4K HLG 휴대폰 영상에서 매우 빠른 스크럽이 초당 약 4프레임에서 60프레임으로 개선됐다(Apple M5 실측).
- **화면 전환 11종**: Cross Dissolve·Dip to Black·Dip to White(디졸브), Push·Slide·Whip Pan·Zoom(모션), Wipe·Iris(와이프), Blur·Pixelate(스타일). Push·Slide·Whip Pan·Wipe는 방향을 고를 수 있다. 컷 전환은 컷을 중심으로 양쪽에 반씩 걸리고(홀수 프레임은 컷 뒤), 페이드는 클립 안쪽에서 재생되며 아래 트랙이 비친다. 종류마다 기본 길이가 있고(0.4–1초) 최대 5초, 클립 길이에 맞춰 자동으로 줄어든다. 트림·이동·분할·삭제·속도 변경을 따라가며, 클립이 더 이상 맞닿지 않으면 사라진다.
  - 오른쪽 **TRANSITIONS** 카드의 이미지나 이름을 잡아 타임라인으로 드래그한다. 클립 위에서는 가까운 시작·끝을, 맞닿은 경계에서는 두 클립 사이를 선택하며 파란 표시가 적용 위치·길이를 미리 보여준다. 기존 전환 위에 놓으면 길이·방향을 유지해 종류만 바꾼다. 오디오 트랙과 경계에서 먼 빈 공간에는 적용하지 않는다. 적용·교체는 ⌘Z/⇧⌘Z로 되돌릴 수 있다.
  - 타임라인 전환의 **양끝 핸들을 좌우로 드래그**해 길이를 조절한다. 컷 전환은 중심을 유지하면서 양쪽이 함께 늘고 줄며, 페이드 인은 오른쪽 끝, 페이드 아웃은 왼쪽 끝으로 조절한다. 드래그 중 초·프레임 길이를 표시하고 마우스를 놓으면 미리보기와 인스펙터에 반영한다. 프레임 단위로 맞추고 최소 1프레임·최대 5초 및 이웃 전환/클립의 남은 길이를 지킨다. 스냅은 Shift로 일시 해제, Escape는 취소, 한 번의 드래그는 한 번의 Undo이다.
  - 두 그림을 함께 보여 주는 전환은 컷 너머의 원본 프레임(핸들)을 A/B 두 합성 트랙으로 동시에 디코딩한다. 원본이 부족하면 있는 만큼 쓰고 나머지는 **첫·마지막 프레임을 정지**해 채운다(영상 트랙이 오디오보다 짧아도 마지막 프레임). Dip 계열은 컷에서 한 클립씩 바뀌어 핸들이 필요 없다.
  - 합성은 레인 단위로 한다: 나가는 그림과 들어오는 그림을 먼저 합친 뒤 아래 트랙 위에 얹으므로, PiP·자막으로 들어가는 디졸브에서도 나가는 그림이 끝에 갑자기 사라지지 않는다. 디졸브·딥은 Premiere·FFmpeg·Shotcut처럼 **감마(인코딩) 공간**에서 섞는다. 픽셀 단위 값(블러 반경 등)은 1920 폭 기준으로 4K 출력에서 비례한다. Core Image 내장 필터만 써서 Metal 빌드 단계가 없다.
  - 연결 오디오는 양쪽 원본에 컷 너머 소리가 있으면 **이퀄 파워 크로스페이드**(sin/cos 8구간), 없거나 Dip·페이드면 컷 앞에서 줄고 뒤에서 올라온다.
  - 수식·구성 참고: gl-transitions·editly·Cabbage(MIT), FFmpeg xfade·MLT luma(LGPL, 수식만), Olive·Kdenlive·Shotcut·Blender(GPL, UX만 참고), Apple AVCustomEdit(구조만). 코드는 가져오지 않았다.
- **HDR·광색역 원본의 색 변환은 합성기가 직접 한다.** 원본 프레임을 원래 색·포맷(10-bit YCbCr, ProRes 4444는 알파 포함 16-bit)으로 받아 VideoToolbox로 Rec.709로 바꾼다. AVFoundation에 맡기면 스냅샷(이미지 생성기)만 HLG를 톤매핑하지 않아 미리보기보다 밝게 나왔고, 재생·내보내기의 첫 프레임도 그랬다. 이제 미리보기·스냅샷·출력·전환의 정지 프레임이 같은 변환을 거친다([기록](docs/validation/snapshot-color.md)).
- HDR 소스는 디코더가 준비되기까지 세그먼트마다 약 3프레임을 내주지 않는다. 그 구간은 클립의 첫 프레임으로 메워 검은 깜빡임이나 렌더 중단이 생기지 않게 한다.
- 진행률·취소·오류 처리. 성공 전 목적지 파일을 교체하지 않으며 임시 작업 폴더를 정리한다. 원본과 같은 경로로 내보내는 작업은 차단한다.

## 구조

| 경로 | 역할 |
|---|---|
| `Sources/FrameCore` | UI·AVFoundation과 분리된 Codable 모델, 정수 틱 시간, 편집 연산, 검증, Undo/Redo |
| `Sources/FrameMedia` | 가져오기·북마크·캐시, AVComposition 생성, Core Image 커스텀 합성, MP4 reader/writer |
| `Sources/FrameStudio` | SwiftUI 패널, AppKit 타임라인/드래그/플레이어, 비동기 상태 관리 |
| `Sources/FrameProbe` | 실제 미디어를 쓰는 통합 검증 실행기 |
| `Tests/FrameCoreTests` | 시간·연결 편집·원자성·저장 복원·잘못된 문서 검증 |

시간은 초당 600,000 정수 틱으로 표현한다. 24/25/30/50/60 및 24000/1001·30000/1001·60000/1001 프레임이 정확한 정수 틱이다. 재생·출력 시에만 CMTime/AVComposition으로 변환하고 MP4 트랙·무비 시간 단위도 같은 정밀도를 사용한다. `@unchecked Sendable`은 생성 후 불변으로 공유하는 AVFoundation/CI 객체와 잠금·직렬 큐로 보호되는 합성기 경계에 한정했다.

## 검증 실행

단위 테스트에는 외부 도구가 필요 없다.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --arch arm64
```

통합 검증에는 테스트 픽스처 생성·독립 분석용 `ffmpeg`(libx265·VideoToolbox 인코더 포함), `ffprobe`, Python 3가 필요하다. 이들은 앱에 포함되거나 앱에서 호출되지 않는다. 스모크 검증은 29.97fps 4K HLG 세로 영상의 프록시 크기·방향·색 태그·프레임별 타임스탬프 일치와 원본 대비 미리보기 차이, 첫 프레임이 늦게 디코딩되는 영상의 미리보기 첫 프레임, 그리고 프록시를 만들면 안 되는 영상(BT.470BG 태그·알파·비정사각 픽셀)도 확인한다. 화면 전환은 11종(방향 포함 15가지)의 중간 프레임 색, 감마 공간 블렌드, PiP로 들어가는 디졸브, 원본이 모자랄 때의 마지막 프레임 정지(영상이 오디오보다 짧은 `shortpicture.mp4` 포함), 이퀄 파워 크로스페이드, 출력 MP4를 확인한다.

```sh
./scripts/validate.sh
```

스냅샷만 검증하려면 기존 픽스처를 사용해 다음 명령을 실행한다. 영상 겹침·효과·텍스트·이미지·빈 구간·마지막 프레임의 PNG를 MP4 출력과 비교하고 색상 프로필, 취소와 실패 시 기존 파일 보존을 확인한다.

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift run --arch arm64 FrameProbe snapshot TestArtifacts/fixtures TestArtifacts/snapshot-validation
```

영상 비율·프레임률 변경과 세로 4K 출력은 `FrameProbe video-settings TestArtifacts/fixtures TestArtifacts/video-settings`로 검증한다. [검증 결과](docs/validation/video-settings.md).

폰트는 스모크 검증에 포함된다(시스템 폰트의 이름만 바꿔 어떤 Mac에도 없는 폰트를 만들어 추가·제목 렌더·출력 일치·저장·없는 폰트 대체를 확인한다). 받은 폰트로 직접 확인하려면 `FrameProbe fonts TestArtifacts/fixtures <출력 폴더> <폰트 파일 또는 ZIP…>`를 실행한다. 폰트는 출력 폴더 안의 임시 폴더에만 추가된다. [폰트 검증 결과](docs/validation/fonts.md).

[스냅샷·클립 이동 검증 기록](docs/validation/snapshot-navigation.md)에 실제 실행 결과와 확인하지 못한 항목을 정리했다.

PNG 재가져오기 색상 회귀 검증은 `FrameProbe snapshot-roundtrip --chart TestArtifacts/snapshot-color-chart`로 실행한다. `--chart` 대신 영상/이미지 경로도 사용할 수 있다. 중간톤 차트를 캡처·재가져오기 3회 반복하고 MP4 출력까지 비교한다. [색공간 수정 기록](docs/validation/snapshot-color.md)을 참고한다.

결과는 `TestArtifacts/results/`에 생성된다. `Validation.framestudio`에는 검증 타임라인이 저장된다. FrameProbe가 만든 보안 북마크는 앱의 접근 권한과 다르므로, 앱에서 처음 열 때 라이브러리의 Relink로 해당 픽스처를 선택해야 한다. 이번 GUI 검증에서 앱으로 저장한 `TestArtifacts/fixtures/GUI-Automation.framestudio`도 제공한다. [실제 검증 기록](docs/validation/RESULTS.md)과 [오픈소스·Apple 자료 검토](docs/research/implementation-review.md)를 참고한다.

## 현재 제한

- 영상 비율은 다섯 가지 프리셋을 지원하며 임의 픽셀 크기 입력은 없다. 저장 형식은 버전 2이며 버전 1 문서는 16:9로 읽는다. 버전 2 문서는 이전 Ara에서 열 수 없다. 한 번에 한 프로젝트/클립 선택. 트랙 순서 변경 UI는 없고, 클립이 있는 트랙은 비운 뒤에 지울 수 있다. V3 이상 또는 A3 이상을 쓴 문서는 이 기능 이전 버전의 Ara에서 열리지 않는다. 같은 레인 덮어쓰기·리플 편집·키프레임·오디오 분리/재연결 UI는 없다. 전환은 영상·이미지·텍스트 클립에만 걸리며, 오디오만 있는 클립 사이의 크로스페이드·사용자 정의 전환·이징 곡선 편집은 없다. Dip 계열은 해당 트랙의 그림만 검정/흰색으로 바꾼다(자막에 걸면 글자가 검정에서 밝아진다; 투명하게 나타나게 하려면 Cross Dissolve를 쓴다).
- 출력은 SDR Rec.709만 지원한다. HDR 영상(PQ·HLG, BT.2020, 10-bit)은 **가져올 수 있으며 SDR Rec.709로 톤매핑**해 편집·출력한다. HDR을 HDR로 유지하는 출력은 범위 밖이다. 표시된 log와 Dolby Vision(dvh1/dvhe), 고비트 심도 및 HDR 게인맵 **이미지** 입력은 여전히 오류로 거부한다. HEIC/RAW는 지원하지 않는다. 색 정보가 잘못되거나 없는 파일의 원래 촬영 모드는 자동 판별할 수 없다.
- 휴대폰 세로 영상처럼 회전 정보(표시 행렬)가 붙은 영상은 그 방향대로 미리보기·출력한다(90°·180°·270°·좌우 반전 검증).
- AVFoundation이 읽을 수 있는 미디어의 첫 영상/오디오 스트림을 사용한다. DRM 파일은 지원하지 않는다. 모든 카메라·코덱 조합을 시험한 것은 아니다.
- 표시는 NDF다. 드롭 프레임 타임코드·OTIO/FCPXML 교환·고급 HDR·멀티캠·플러그인·AI는 범위 밖이다. 프록시는 미리보기용 FHD 프록시만 자동으로 만들며, 프록시로 편집·출력하는 기능이나 수동 관리 UI는 없다. 1080p 이하 영상은 프록시 없이 원본으로 미리보기한다.
- 썸네일은 원본당 대표 이미지, 파형은 최대 16,000 peak다. 긴 영상의 모든 프레임을 메모리에 올리지 않지만 수 시간 프로젝트·수천 클립의 성능은 실측하지 않았다. 미디어 캐시 자동 용량 제한과 크래시 후 자동 복구는 없다(프록시는 30일 미사용 시 정리하지만 용량 상한은 없다. 4K60 원본 1분당 약 90–100MB).
- 저장은 수동이다. 앱 재실행 후 접근은 북마크로 복원하지만, 이동식 디스크 권한 변화·다른 Mac으로 문서 이동 시 재연결이 필요할 수 있다.
- macOS 15 최소 타깃 빌드는 확인했다. macOS 15 실제 장비, Intel, 배포 서명/공증, 앱 샌드박스에서는 검증하지 않았다.
